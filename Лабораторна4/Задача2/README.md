Задача 2
Завдання: Калькулятор валют. Користувач вводить номер операції:
1 — гривня → долар,
2 — гривня → євро,
3 — долар → гривня,
4 — євро → гривня.
Програма запитує суму і виконує відповідний розрахунок за фіксованим
курсом.

Опис роботи: Програма виводить меню валютних операцій. Користувач вводить номер операції. Після цього програма запитує суму коштів. Залежно від вибраного пункту за допомогою оператора switch виконується відповідний розрахунок та виводиться результат.

Алгоритм роботи програми: 
1.Початок програми
2.Вивести меню валютних операцій
3.Ввести номер операції
4.Ввести суму коштів
5.Виконати перерахунок за допомогою switch:
1 — гривні перевести в долари
2 — гривні перевести в євро
3 — долари перевести в гривні
4 — євро перевести в гривні
6.Вивести результат
7.Кінець програми

Синтаксис використаних операторів: Оператор cout використовується для виведення меню та результату обчислення.Оператор cin використовується для введення номера операції та суми грошей.Оператор switch використовується для вибору потрібної операції конвертації.Оператор case визначає, яку саме валютну операцію буде виконано.Оператор break завершує виконання вибраного варіанта case.Оператор default використовується для повідомлення про неправильний вибір операції.

Пояснення коду: У програмі оголошуються змінні для збереження номера операції та суми коштів. Після введення даних оператор switch порівнює номер операції з можливими варіантами. Для кожного case виконується свій розрахунок за заздалегідь заданим валютним курсом. Результат виводиться на екран

Інструкція використання програми:
1.Запустити програму.
2.Обрати номер операції:
1 — гривня → долар
2 — гривня → євро
3 — долар → гривня
4 — євро → гривня
3.Ввести суму коштів.
4.Натиснути Enter.

Очікувані результати: Програма виводить суму після конвертації у вибрану валюту за фіксованим курсом.
У разі неправильного введення номера операції виводиться повідомлення про помилку.
