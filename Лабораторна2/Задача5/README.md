Задача 5
 Калькулятор знижок у магазині. Програма визначає знижку на товар  залежно від суми покупки: 
− <100 грн → 0% 
− 100–499 грн → 5% 
− 500–999 грн → 10% 
− ≥1000 грн → 15% 

Алгоритм (блок-схема):
Вхід → Ввести суму покупки → Перевірити умови:
suma < 100 → discount = 0 → Вивести знижку → Розрахувати suma2 → Вивести суму до оплати → Вихід
100 ≤ suma < 500 → discount = 5 → Вивести знижку → Розрахувати suma2 → Вивести суму до оплати → Вихід
500 ≤ suma < 1000 → discount = 10 → Вивести знижку → Розрахувати suma2 → Вивести суму до оплати → Вихід
suma ≥ 1000 → discount = 15 → Вивести знижку → Розрахувати suma2 → Вивести суму до оплати → Вихід

Синтаксис використаних операторів мови C++:
cin >>, cout <<, if, else if, else, double, арифметичні оператори *, /, логічні оператори <, >=, &&

Пояснення коду:
Спочатку оголошуються змінні suma типу double для введеної суми покупки та discount для зберігання відсотка знижки, ініціалізований 0. Програма виводить повідомлення "Сума покупки: " і зчитує число через cin >> suma. Далі використовуються умовні оператори if та else if для визначення знижки: якщо сума менша за 100 грн – знижка 0%; від 100 до 499 включно – 5%; від 500 до 999 – 10%; від 1000 і більше – 15%. Після визначення знижки програма виводить відсоток знижки та розраховує суму до оплати за формулою suma2 = suma * (1 - discount / 100). Нарешті, програма виводить суму до оплати і завершує роботу з return 0;. Таким чином, користувач вводить суму покупки, а програма автоматично обчислює відсоток знижки і фінальну суму до оплати.

Інструкція використання:
Запустити програму.
Ввести суму покупки.
Отримати відсоток знижки та суму до оплати.

Приклад введення: Сума покупки: 479
Очікуваний результат:
Знижка: 5
Сума до оплати: 455.05
