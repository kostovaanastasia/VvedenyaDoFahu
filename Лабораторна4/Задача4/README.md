Завдання 4
Завдання: 4. Оцінка якості обслуговування. Користувач вводить оцінку (1–5).
Програма виводить текст:
1 — “Дуже погано”,
2 — “Погано”,
3 — “Задовільно”,
4 — “Добре”,
5 — “Відмінно”.

Опис роботи: Програма запитує у користувача оцінку якості обслуговування. Після введення числа програма за допомогою оператора switch визначає, якій оцінці відповідає введене значення, та виводить відповідний текстовий опис. Якщо користувач вводить число, що не входить у діапазон від 1 до 5, програма повідомляє про помилку.

Алгоритм роботи програми:
Початок програми
Запросити у користувача оцінку якості обслуговування
Ввести оцінку
Перевірити введене значення за допомогою switch:
якщо 1 → вивести «Дуже погано»
якщо 2 → вивести «Погано»
якщо 3 → вивести «Задовільно»
якщо 4 → вивести «Добре»
якщо 5 → вивести «Відмінно»
інакше → вивести повідомлення про помилку
Кінець програми

Синтаксис використаних операторів:Оператор cout використовується для виведення повідомлень та результату оцінювання.Оператор cin використовується для введення оцінки користувачем.Оператор switch використовується для вибору текстового опису оцінки.Оператор case визначає, який текст буде виведено для відповідної оцінки.Оператор break завершує виконання відповідного варіанта case.Оператор default використовується у разі неправильного введення оцінки.

Пояснення коду: У програмі оголошується змінна для збереження оцінки. Користувач вводить число від 1 до 5. Оператор switch порівнює введене значення з можливими варіантами. Для кожного варіанта case виводиться відповідний текстовий опис якості обслуговування. Якщо введене число не відповідає жодному з варіантів, виконується оператор default, який повідомляє про помилку.

Інструкція використання програми:
Запустити програму.
Ввести оцінку від 1 до 5.
Натиснути Enter.

Очікувані результати: При введенні числа від 1 до 5 програма виведе відповідну текстову оцінку.При введенні некоректного значення буде виведено повідомлення про помилку.
