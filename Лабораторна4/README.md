                     Задача 1
Завдання: Меню кавової машини. Користувачу друкується меню кавової машини:
1 — Еспресо
2 — Американо
3 — Капучино
4 — Лате
5 — Какао
Користувач обирає номер напою (1–5). Програма виводить назву напою тайого вартість.

Опис роботи: Програма виводить на екран меню кавової машини.Користувач вводить номер напою. За допомогою оператора switch відбувається перевірка введеного значення та виводиться відповідний результат — назва напою та його ціна.Якщо введене число не входить у діапазон від 1 до 5, програма виводить повідомлення про помилку.

Алгоритм роботи програми: 
1.Початок програми
2.Вивести меню кавових напоїв
3.номер напою
4.Перевірити номер за допомогою switch:
якщо 1 → вивести «Еспресо – 45 грн»
якщо 2 → вивести «Американо – 50 грн»
якщо 3 → вивести «Капучино – 49 грн»
якщо 4 → вивести «Лате – 60 грн»
якщо 5 → вивести «Какао – 55 грн»
інакше → вивести повідомлення про помилку
5.Кінець програми

Синтаксис використаних операторів:Оператор cout використовується для виведення інформації на екран. За його допомогою виводиться меню кавової машини та результат вибору користувача.Оператор cin використовується для введення даних з клавіатури. Він зчитує номер напою, який вводить користувач.Оператор switch використовується для вибору одного з кількох варіантів виконання програми. Він перевіряє значення змінної, введеної користувачем.Оператор case використовується всередині оператора switch. Він визначає варіант, який буде виконано, якщо значення співпадає з певним числом.Оператор break використовується для завершення виконання вибраного варіанта case та виходу з оператора switch.Оператор default використовується для обробки неправильного введення. Він виконується тоді, коли жоден case не підходить.

Інструкція використання програми
1.Запустити програму.
2.Ознайомитися з меню напоїв.
3.Ввести число від 1 до 5:
1 → Еспресо
2 → Американо
3 → Капучино
4 → Лате
5 → Какао
4.Натиснути Enter.

Очікувані результати: При введенні коректного числа — виводиться назва напою та його ціна. При введенні некоректного значення — повідомлення: «Введіть від 1 до 5»
                    Задача 2
Завдання: Калькулятор валют. Користувач вводить номер операції:
1 — гривня → долар,
2 — гривня → євро,
3 — долар → гривня,
4 — євро → гривня.
Програма запитує суму і виконує відповідний розрахунок за фіксованим
курсом.

Опис роботи: Програма виводить меню валютних операцій. Користувач вводить номер операції. Після цього програма запитує суму коштів. Залежно від вибраного пункту за допомогою оператора switch виконується відповідний розрахунок та виводиться результат.

Алгоритм роботи програми: 
1.Початок програми
2.Вивести меню валютних операцій
3.Ввести номер операції
4.Ввести суму коштів
5.Виконати перерахунок за допомогою switch:
1 — гривні перевести в долари
2 — гривні перевести в євро
3 — долари перевести в гривні
4 — євро перевести в гривні
6.Вивести результат
7.Кінець програми

Синтаксис використаних операторів: Оператор cout використовується для виведення меню та результату обчислення.Оператор cin використовується для введення номера операції та суми грошей.Оператор switch використовується для вибору потрібної операції конвертації.Оператор case визначає, яку саме валютну операцію буде виконано.Оператор break завершує виконання вибраного варіанта case.Оператор default використовується для повідомлення про неправильний вибір операції.

Пояснення коду: У програмі оголошуються змінні для збереження номера операції та суми коштів. Після введення даних оператор switch порівнює номер операції з можливими варіантами. Для кожного case виконується свій розрахунок за заздалегідь заданим валютним курсом. Результат виводиться на екран

Інструкція використання програми:
1.Запустити програму.
2.Обрати номер операції:
1 — гривня → долар
2 — гривня → євро
3 — долар → гривня
4 — євро → гривня
3.Ввести суму коштів.
4.Натиснути Enter.

Очікувані результати: Програма виводить суму після конвертації у вибрану валюту за фіксованим курсом.
У разі неправильного введення номера операції виводиться повідомлення про помилку.
