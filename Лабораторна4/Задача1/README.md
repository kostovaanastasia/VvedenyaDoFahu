Задача 1
Завдання: Меню кавової машини. Користувачу друкується меню кавової машини:
1 — Еспресо
2 — Американо
3 — Капучино
4 — Лате
5 — Какао
Користувач обирає номер напою (1–5). Програма виводить назву напою тайого вартість.

Опис роботи: Програма виводить на екран меню кавової машини.Користувач вводить номер напою. За допомогою оператора switch відбувається перевірка введеного значення та виводиться відповідний результат — назва напою та його ціна.Якщо введене число не входить у діапазон від 1 до 5, програма виводить повідомлення про помилку.

Алгоритм роботи програми: 
1.Початок програми
2.Вивести меню кавових напоїв
3.номер напою
4.Перевірити номер за допомогою switch:
якщо 1 → вивести «Еспресо – 45 грн»
якщо 2 → вивести «Американо – 50 грн»
якщо 3 → вивести «Капучино – 49 грн»
якщо 4 → вивести «Лате – 60 грн»
якщо 5 → вивести «Какао – 55 грн»
інакше → вивести повідомлення про помилку
5.Кінець програми

Синтаксис використаних операторів:Оператор cout використовується для виведення інформації на екран. За його допомогою виводиться меню кавової машини та результат вибору користувача.Оператор cin використовується для введення даних з клавіатури. Він зчитує номер напою, який вводить користувач.Оператор switch використовується для вибору одного з кількох варіантів виконання програми. Він перевіряє значення змінної, введеної користувачем.Оператор case використовується всередині оператора switch. Він визначає варіант, який буде виконано, якщо значення співпадає з певним числом.Оператор break використовується для завершення виконання вибраного варіанта case та виходу з оператора switch.Оператор default використовується для обробки неправильного введення. Він виконується тоді, коли жоден case не підходить.

Інструкція використання програми
1.Запустити програму.
2.Ознайомитися з меню напоїв.
3.Ввести число від 1 до 5:
1 → Еспресо
2 → Американо
3 → Капучино
4 → Лате
5 → Какао
4.Натиснути Enter.

Очікувані результати: При введенні коректного числа — виводиться назва напою та його ціна. При введенні некоректного значення — повідомлення: «Введіть від 1 до 5»
